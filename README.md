# ChaatMap – StreetBite Safety Sprint

## Start the app
1. Install Node.js 18 or later.
2. Extract this project folder.
3. Open a terminal inside the folder.
4. Run:
   ```bash
   npm install
   npm run dev
   ```
5. Open **http://localhost:5173** in your browser.

The React frontend runs on port 5173 and the Express API on port 4000.

## What to demo
- Search Pani Puri and filter Sindhi Colony.
- Open a vendor from a map pin or card.
- Submit four structured hygiene ratings (1–5).
- See the composite score recalculate.
- Send a hygiene concern report.
- Browse the sample food trails.

## Important
All included vendors, locations, ratings, reviews, routes, prices, and hours are **synthetic demo data**, not real verified listings. FSSAI badges are deliberately not shown as verified. Do not use the demo scores as proof of safety or as claims about real vendors.

See `docs/PROJECT_REPORT.md` for architecture, formula, API routes, limitations, and evaluation checklist.
